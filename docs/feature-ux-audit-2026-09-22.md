# 기능·출시 UX 점검 — 2026-09-22

## 판정 기준

실제 사용자별 이용 통계가 없으므로 **사용률**을 판단한 문서가 아닙니다. 앱의 화면·호출 코드, 서버 계약, 공개 운영 API 응답을 기준으로 기능 연결 상태를 구분했습니다. 로그인·푸시 수신·계정별 쓰기 동작은 이번 점검에서 운영 계정으로 실행하지 않았습니다.

## 기능 구분

| 구분 | 기능 | 확인 결과 / 처리 |
|---|---|---|
| 핵심 · 운영 응답 확인 | 오늘 브리프, 시장 요약 | 운영 API에서 데이터 반환 확인. 결론과 쉬운 안내를 먼저 표시하고 시장 흐름·근거는 기본 접힘. |

| 핵심 · 화면/API 연결 | 검색, 관심종목, 보유종목, 가격 기준 점검 | 조회·저장 경로와 상세 화면 연결 확인. 이번 변경은 매매 로직을 변경하지 않음. 관심 신호 클릭 시 종목 상세로 이동. |

| 부가 · 연결된 기능 | 모의투자(기존 리그) | 리그 생성·참가·가상 매매 화면/API가 있음. 실제 증권 주문 아님. 탭 이름을 명확하게 변경, 기능 보존. |

## 이번 UX 변경

- 오늘 화면: 간단한 확인 안내 → 브리프 → 내 종목 → 시장 세부 정보 순서. 선택한 한국/미국에 맞게 브리프·보유 수·신호·장전 카드 필터 일치.
- 브리프/AI 해설: 핵심 제목, 발행·분석 시각, 쉬운 안내, 사용자가 펼치는 시장 흐름. 긴 근거는 문단별로 분리하며 원문 수치·근거를 새로 만들지 않음.
- 발행 후 24시간 초과는 이전 자료로 표시. 시각 오류/미래 시각은 시각 확인 필요, 자료 부족은 판단 보류. 24시간은 표시용 기준이며 거래일 최신성이나 매매 적합성을 보장하지 않음.
- 지수: 2.8초 자동 회전 제거. 가로 스크롤 고정 카드, 큰 숫자·등락 부호·상세 진입 제공. 비정상 시세는 0으로 표시하지 않음.
- 신호가 없을 때 `안정 구간`, 낮은 합성 위험에서 `진입하기 무난`처럼 안전·매매 적합성을 단정하던 문구 제거.
- 설정: 시장·테마·알림을 먼저, 플랜·개인 연동은 접어서 제공. 실제 없는 헤더 시장 칩 안내와 개발용 `v2` 문구 정리.
- 탐색 탭: 오늘 / 내 종목 / AI 분석 / 모의투자 / 공유. 주요 안내는 존댓말로 정리.
- 펼침 상태 접근성, 최소 터치 높이, 라이트·다크 대비 개선. 데이터와 계정 기록 삭제 없음.

## 검증 및 릴리스 경계

- `npm run check:types` 통과.
- Jest 6 suites / 45 tests 통과. 새 테스트는 브리프 종류·시장 필터·원문 분리·오래된/잘못된 시각·자료 부족 경계 포함.
- 웹 프로덕션 export 통과. iOS 프로덕션 JS/Hermes bundle export 통과(서명된 IPA 빌드와는 다름).
- 개발 샘플로 390px 휴대폰 너비, 라이트·다크, 브리프/AI 기본 접힘과 열기·닫기, 자료 부족·이전 자료 표시 확인.
- API·DB·trader·실거래 설정 변경 없음. 공개 API는 조회만 수행.
- **이번 변경은 App Store 업로드/심사 제출이 아님.** 배포 전 실제 기기의 로그인·푸시·종목 저장·모달 전환 QA, 로컬 서명 빌드, App Store 제출이 별도로 필요함.
